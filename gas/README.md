# みんなのランキング: Google スプレッドシート + Apps Script

ゲームから「名前・スコア・レベル」を送って、スプレッドシートに貯め、上位100件を全員で共有します。

## しくみ
- ゲームオーバー / ギブアップ(New Game → Yes)のときに、ニックネーム(8文字まで、一度入れたら覚える)を聞いて、スコアを送ります。
- 1人(ブラウザ)につき、ステージごとに1行です。自己ベストを超えたときだけ送り、2回目以降は「ランキングを更新しますか?」と確認します。
- ランキング画面の「Global」で、ステージごとの上位100件が見られます。「Local」は、これまでの自分の記録(ブラウザ内)です。

## 手順 (約10分)
1. [Google スプレッドシート](https://sheets.google.com) で、新しいスプレッドシートを作る(名前は何でもOK)。
2. メニュー **拡張機能 → Apps Script** を開く。
3. 最初からある `コード.gs` の中身を全部消して、このフォルダの **`Code.gs` の中身を貼り付ける**。保存(💾)。
4. 右上の **デプロイ → 新しいデプロイ** をクリック。
   - 種類の選択(歯車)で **ウェブアプリ** を選ぶ。
   - **次のユーザーとして実行: 自分**
   - **アクセスできるユーザー: 全員**
   - **デプロイ** を押す。初回は、アクセスの承認を求められるので、自分のGoogleアカウントで許可する
     (「安全ではないページ」と出たら「詳細」→「(プロジェクト名)に移動」)。
5. 表示された **ウェブアプリのURL**(`https://script.google.com/macros/s/.../exec`)をコピーする。
6. ブラウザでそのURLの末尾に `?stage=yokohama` を付けて開き、`[]` と表示されれば成功。
7. ゲームの `index.html` で、次の1行の `''` の中にURLを貼る。

   ```js
   const LB_URL = (DEV && new URLSearchParams(location.search).get('lb')) || '';
   ```
   ↓
   ```js
   const LB_URL = 'https://script.google.com/macros/s/ここにURL/exec';
   ```
8. `index.html` を GitHub Pages に上げ直して完了。

## コードを直したとき
Apps Script のコードを変えたら、**デプロイ → デプロイを管理 → 編集(鉛筆) → バージョン: 新バージョン → デプロイ** で更新します(URLは変わりません)。

## 気をつけること
- **ごまかし(チート):** スコアは、ブラウザから送られる値なので、書き換えようと思えば、できてしまいます。`Code.gs` では、明らかにおかしい値(スコアが大きすぎる、名前が空など)だけを弾いています。厳しく守りたい場合は、手の記録を送って、サーバーで再計算する仕組みが必要です。
- **名前:** `< > & " '` などの記号は取り除き、8文字までにしています。不適切な名前は、スプレッドシートの行を消せば、反映されます(30秒ほどでランキングから消えます)。
- **個人情報:** 集めるのは、ニックネーム・スコア・レベルだけです。メールアドレスなどは集めません。
- **無料枠:** 個人の遊びで使う分には、足ります。アクセスが非常に多くなると、Google の1日あたりの上限に当たることがあります(一覧は30秒キャッシュして、軽くしています)。
- **ステージの追加:** 新しいステージをゲームに足したら、`Code.gs` の `STAGES` にも、同じIDを足して、再デプロイしてください。
